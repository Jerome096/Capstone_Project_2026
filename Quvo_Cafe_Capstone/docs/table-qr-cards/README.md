# Dine-in table QR cards

Ten branded cards for Tables 1 through 10, using the hosted dine-in ordering site.
The printed domain label has been removed beneath each QR. Each code still opens
its matching table at `https://quvocafe.opik.net/customer/?table=N`.

- [cards-png](cards-png): individual 1800 x 1640 PNG cards for printing.
- [cards-svg](cards-svg): matching scalable artwork with the logo embedded.
- [table-links.csv](table-links.csv): exact table-to-URL mapping.

Place each numbered card on its matching physical table. Keep the complete QR and
its white margin visible, and test a printed card with a phone before placing the
full set. Customers enter their name after scanning and wait for staff approval.

All ten PNG QR codes were decoded and checked against their table links. Removing
the domain label left every pixel outside that text unchanged. The cards retain
their original dimensions. No database records or customer sessions were created.
