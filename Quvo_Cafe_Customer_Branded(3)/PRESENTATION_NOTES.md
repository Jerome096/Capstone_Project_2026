# Customer interface preview

Sample accounts, menu items, customization prices, and order history have been removed.
Open index.html with Live Server to reach online login. Scan assets/qr/table-1.png to preview Table 1 dine-in directly. There is no default login account.
Registration and account editing still use browser storage temporarily; they do not create SQL Server records.
A newly registered test account reaches the empty menu. Orders cannot be submitted without menu items.
Use a table QR URL to preview dine-in. Approval timers remain simulated.
The next integration step is PHP/SQL Server authentication, menu loading, and order persistence.
